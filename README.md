Orayt, jom kita buat **File 2: `README.md`**.

File ni paling penting untuk **Branding** repo kau. Bila orang (atau kau sendiri) buka repo tu kat GitHub, teks dalam file ni la yang akan muncul kat depan skrin untuk terangkan apa benda projek ni.

**Langkah-langkah:**
1.  Klik balik kat nama repo kau (untuk pergi ke main page).
2.  Klik **Add file** > **Create new file**.
3.  Namakan file tu: `README.md` (mesti huruf besar semua).
4.  **Copy & Paste** teks di bawah:

```markdown
# AI Code Separator ✂️

Tool ringkas dan berkuasa untuk mengasingkan **Clean Code** daripada teks perbualan AI (Chatbot). 

## ✨ Kelebihan
- **Smart Detection:** Automatik mengesan blok kod dalam simbol triple backticks (```).
- **Dua Ruang Asing:** Kod bersih di kiri, teks borak di kanan.
- **One-Click Copy:** Salin kod atau teks dengan satu butang pantas.
- **Mobile Friendly:** Rekaan responsive, sedap mata memandang kat phone atau PC.

## 🚀 Cara Guna
1. **Copy** seluruh jawapan panjang dari AI (termasuk borak & kod).
2. **Paste** dalam kotak input di atas.
3. Tekan butang **Asingkan Kod Sekarang**.
4. Klik butang **Copy Code** untuk ambil coding yang dah bersih.

---
*Built with ❤️ using Studio AI Pro*
```

5.  Klik butang hijau **Commit changes**.

---

**💡 Kenapa `README.md` ni power?**
Kalau kau nak tunjuk tool ni kat orang, kau cuma bagi link repo kau je. Orang akan nampak dokumentasi yang kemas macam ni, terus nampak kau ni *Developer* yang tersusun!

Dah siap commit? Bagitau aku, kita buat **Langkah Terakhir (Icon & Link)** pula! 🚀🔥
